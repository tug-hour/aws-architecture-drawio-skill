# AWS作図ルール

基準はRelease 23-2026.01.30。以下の「本文」はPPTX内の規定、「実測」は既定要素の値、「実装」はこのスキルの処理方針を意味する。

| 項目 | 規定または実測 | 出典 |
| --- | --- | --- |
| 図のアイコン | 既定のサイズ・色・形式を使用。切り抜き・回転・反転・形状変更は禁止 | 本文L15/D13 |
| サービス | 基本60 pt角、CloudSearchだけ59.76 pt角 | 実測L31以降/D29以降 |
| リソース・汎用 | 36 pt角。Marketplaceは60 pt角 | 実測L28以降/D26以降 |
| グループ内アイコン | 30 pt角で、拡縮禁止 | 実測L25–26/D23–24、本文L14/D12 |
| カテゴリ見出し | 67 pt角 | 実測L30以降/D28以降 |
| グループ枠 | 1.25 pt、塗りなし。Region=sysDash、AZ=dash | 実測L25/D23 |
| 入れ子 | 四辺に最低0.05インチ＝3.6 ptの余白 | 本文L14/D12 |
| 通常ラベル | 12 pt Arial | 本文L17/D15 |
| サービス名 | 最大2行。AWS／Amazonを先頭語と同じ行に置き、単語途中の改行禁止 | 本文L17/D15 |
| 略称 | 文書内で正式名を先に示す。異なるサービスで同じ略称を使わない | 本文L17/D15 |
| 接続 | 既定またはデフォルト矢印。直線・直角を優先 | 本文L16/D14 |
| 通常矢印 | 1.25 pt・実線、Open Arrow（arrow/med/sm） | 実測L27/D25 |
| コールアウト | 既定形式。大小を混在させず、文字・記号や新しい形へ変更しない | 本文L18/D16 |
| コールアウト寸法 | 大25.92 pt／文字14 pt太字、小21.6 pt／文字11 pt太字 | 実測L18/D16 |

lightは白背景、黒ラベル・黒AWS Cloud枠・黒矢印・黒地白文字コールアウト。darkは黒背景、白ラベル・白AWS Cloud枠・#8FA7C4の矢印・白地黒文字コールアウト。カテゴリ色は共通。汎用アイコンとAWS Cloudアイコンは背景専用ファイルを使う。濃色の微差やSVG内色を一括変換しない。

汎用ラベルは用途に合わせて変更できる。サーバーレスの個別サービスは機能別カテゴリから選ぶ。カスタムグループはカテゴリ色と公式の承認されたアイコンから構成する。Arch_32のSVGを参照する規定を、任意のPNGや縮小したサービスアイコンで代用しない。

白背景の縦長文書は468×630 pt。Training and Certificationは白背景、16 pt黒文字、可視線2 pt、アイコンの色・寸法と線色を保持する。これらは初版の対象外。通常用途の値を適用して対応済みと扱わない。

適用順序は用途別本文→通常本文→個別実測→実装方針。サービス名の2行規定を任意ラベルへ転用しない。本文と実測に衝突があれば推測で解決しない。

この版はdraw.io標準図形を描画基盤に使う。枠の色・線幅・塗り、30 ptのグループ記号、両テーマのラベルと接続に対応した。実装の対応範囲とネイティブ記号の輪郭・矢じりの差は[native-rules.md](native-rules.md)を参照する。PPTX画像ファイルそのものを用いる原仕様からの変更を、完全一致として扱わない。
