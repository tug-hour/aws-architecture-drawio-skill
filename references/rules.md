# AWS PPTXの表現規則とdraw.ioへの適用

Release 23-2026.01.30のLight／Dark PPTXを基準とする。本文の規則と既定要素の実測を区別し、出典の版・ハッシュは[provenance.json](provenance.json)に保持する。元資料は[AWS Architecture Icons](https://aws.amazon.com/architecture/icons/)。このスキルは画像ファイルを同梱せず、draw.io標準AWS図形で表現する。

| 項目 | PPTXの規則・実測と適用値 |
| --- | --- |
| アイコン | 既定の色・比率・形式を保持し、切り抜き・回転・反転・変形をしない（本文L15/D13） |
| サービス | 基本60pt＝80px。CloudSearchは59.76pt＝79.68px（実測L31以降/D29以降） |
| リソース・汎用 | 36pt＝48px。Marketplaceは60pt（実測L28以降/D26以降） |
| グループ記号 | 30pt＝40px。カテゴリ見出しは67pt。任意に縮小しない（L25–26、L30以降/D23–24、D28以降） |
| 枠 | 塗りなし、1.25pt＝1.6667px。Regionは線幅比3:1、AZ等のdashは4:3。入れ子は四辺に最低3.6pt＝4.8pxの余白（本文L14/D12、実測L25/D23） |
| 文字 | 通常の記号・接続ラベルは12pt＝16px Arial。日本語Arial Unicode MSは実装上の拡張（本文L17/D15） |
| サービス名 | 最大2行、AWS／Amazonを最初のサービス語と同じ行に置き、単語途中で改行しない。略称は正式名を先に示し、異なるサービスで同じ略称を使わない（本文L17/D15） |
| 接続 | 実線1.25pt、直線・直角を優先。draw.io標準Open、塗りなし、サイズ6pxを使う。方向は通信の意味に合わせる（本文L16/D14、実測L27/D25） |
| コールアウト | 既定形式を使い大小を混在させない。大25.92pt／文字14pt太字、小21.6pt／文字11pt太字（本文・実測L18/D16） |

1pt＝4/3px。draw.ioの座標・style値はpxで指定する。サービスはカテゴリ色の外形に白い標準記号を縦横比を保って重ね、記号は外形の70%を目安とする。リソースにサービス用の色付き背景を付けない。

lightは白背景・黒文字・黒Cloud枠・黒接続・黒地白文字コールアウト。darkは黒背景・白文字・白Cloud枠・#8FA7C4の接続・白地黒文字コールアウト。カテゴリ色は共通。原本のmxGraphModelはadaptiveColors="none"にする。図形カタログは初期値の参照情報であり許可リストではない。pptx_matchと、記録がある項目のsource_refでPPTXとの照合状況・出典を参照できる。未照合の暫定値をPPTX適合確認済みとは扱わない。未知の標準図形はshape・寸法・色を明示して使え、記録がないことを拒否理由にしない。

AWS Cloudの既定記号はAWSロゴ。元資料でロゴを使えない地域に該当する場合は標準のcloud記号を選ぶ。AWS Cloud記号の濃色はlightで#242F3E、darkで白地に#232F3E。AZ・Security groupなど既定に記号のない枠へ記号を足さない。ASGの横断枠は所属コンテナと区別する。

正式サービス名と役割説明を分け、AZ枠で所属が明らかなら役割ラベルへAZ名を繰り返さない。主要構成・接続を説明文だけで代替しない。通信の種類を独自の線色や破線へ変換せず、必要な意味はラベルで示す。

図形の輪郭・抜き・矢じりはPPTXの画像と近似であり、画素の完全一致を目指す追加調整や検証は行わない。通常ラベルの規則を図の題名や任意の役割説明へ一律転用しない。用途別の規定が異なるTraining and Certificationや縦長文書を依頼された場合は該当する原資料を確認し、この表だけで適合と扱わない。
