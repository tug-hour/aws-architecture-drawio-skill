# AWS PPTXの表現規則とdraw.ioへの適用

Release 23-2026.01.30のLight／Dark PPTXを基準とする。出典の版・ハッシュは[provenance.json](provenance.json)に保持する。元資料は[AWS Architecture Icons](https://aws.amazon.com/architecture/icons/)。このスキルは画像ファイルを同梱せず、draw.io標準AWS図形で表現する。

以下の区分は、本文の指定・禁止・例示と本スキルの採用判断に基づく。「必須」は本スキルで守る条件、「推奨」は通常採用する優先案、「実測」は既定要素から読み取った適用値である。本文の表現とスキル側の採用判断は、該当行で区別する。既定寸法・色を保持する必須条件には、この実測値を用いる。推奨との差だけを必須条件の違反とはせず、原資料より強く採用した条件をPPTX本文の要求そのものとは説明しない。日本語説明やネイティブ図形の近似は、PPTX本文とは別の独自拡張として扱う。

| 区分 | 項目 | 内容・適用値と出典 |
| --- | --- | --- |
| 必須 | アイコン | 既定の寸法・色・比率・形式を保持し、拡縮・切り抜き・回転・反転・変形をしない（本文L14–15/D12–13） |
| 実測 | サービス | 基本60pt＝80px。CloudSearchは59.76pt＝79.68px（L31以降/D29以降） |
| 実測 | リソース・汎用 | 36pt＝48px。Marketplaceは60pt（L28以降/D26以降） |
| 実測 | グループ記号 | 30pt＝40px。カテゴリ見出しは67pt（L25–26、L30以降/D23–24、D28以降） |
| 実測 | 枠 | 塗りなし、1.25pt＝1.6667px。Regionは線幅比3:1、AZ等のdashは4:3（L25/D23） |
| 必須 | 入れ子 | 四辺に最低3.6pt＝4.8pxの余白を保つ。本文L14/D12はshouldであり、本スキルでは最低余白の条件として必須に採用する |
| 推奨 | 文字 | 通常の記号・接続ラベルは12pt＝16px Arialを使う。本文L17/D15はshouldであり、本スキルでは通常採用する推奨値とする |
| 必須 | サービス名・略称 | サービス名は最大2行、AWS／Amazonを最初のサービス語と同じ行に置き、単語途中で改行しない。略称は正式名を文書中で先に示し、異なるサービスで同じ略称を使わない（本文L17/D15） |
| 推奨 | 名称の改行 | 必要なら2語目の後で改行する。例：`Amazon Simple`と`Queue Service`の2行（本文L17/D15のDO） |
| 必須 | 矢印の形式 | PPTXの既定またはデフォルトの矢印を使う。標準draw.ioでの近似は下記の独自拡張と区別する（本文L16/D14） |
| 推奨 | 接続経路 | 直線・直角を優先する（本文L16/D14） |
| 実測 | 接続 | 実線1.25pt＝1.6667px（L27/D25） |
| 必須 | コールアウト | 既定形式を使い大小を混在させない（本文L18/D16） |
| 実測 | コールアウト | 大25.92pt／文字14pt太字、小21.6pt／文字11pt太字（L18/D16） |

独自拡張・近似：日本語にはArial Unicode MSを使い、必要な役割説明をサービス名と分けて保持できる。サービスはカテゴリ色の外形に白い標準記号を縦横比を保って重ね、記号は外形の70%を目安とする。リソースにサービス用の色付き背景を付けない。矢じりはdraw.io標準Open・塗りなし・6pxを使う。図形の輪郭・抜き・矢じりはPPTXの画像と近似であり、画素の完全一致を目指す追加調整や検証は行わない。1pt＝4/3pxで、draw.ioの座標・style値はpxで指定する。

lightは白背景・黒文字・黒Cloud枠・黒接続・黒地白文字コールアウト。darkは黒背景・白文字・白Cloud枠・#8FA7C4の接続・白地黒文字コールアウト。カテゴリ色は共通。原本のmxGraphModelはadaptiveColors="none"にする。図形カタログは初期値の参照情報であり許可リストではない。pptx_matchと、記録がある項目のsource_refでPPTXとの照合状況・出典を参照できる。未照合の暫定値をPPTX適合確認済みとは扱わない。未知の標準図形はshape・寸法・色を明示して使え、記録がないことを拒否理由にしない。

AWS Cloudの既定記号はAWSロゴ。元資料でロゴを使えない地域に該当する場合は標準のcloud記号を選ぶ。AWS Cloud記号の濃色はlightで#242F3E、darkで白地に#232F3E。AZ・Security groupなど既定に記号のない枠へ記号を足さない。ASGの横断枠は所属コンテナと区別する。

名称・改行・日本語の役割説明は、セルが別でも一つの表示ラベルとして選び、見える行数・情報の重複・揃い方・配線との関係を判断する。必要な情報を失わずに済む案では、短縮・重複説明の省略・説明の配置先の変更によって、表示を簡潔にする方を優先する。略称は文書中の正式名の先行表記と合わせて選び、カタログのnameを使うだけで名称規則を満たしたとしない。PPTXの2行規定はサービス名に対するもので、説明を合算した一律の行数制限は追加しない。一方、名称2行＋説明1行を、別セルであることや明文の禁止がないことだけを理由に採用しない。識別や接続の意味に必要な役割説明は保持し、移す場合も対象との対応を保つ。AZ枠で所属が明らかなら役割ラベルへAZ名を繰り返さない。主要構成・接続を説明文だけで代替しない。接続方向は通信の意味に合わせ、通信の種類を独自の線色や破線へ変換せず、必要な意味はラベルで示す。

図の題名・節見出しとアイコン／接続ラベルは区別し、サービス名の改行規定を役割説明へ一律転用しない。用途別の規定が異なるTraining and Certificationや縦長文書を依頼された場合は該当する原資料を確認し、この表だけで適合と扱わない。
